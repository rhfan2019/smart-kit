# 07 验收标准

> 状态：现行 · 2026-11-14。
>
> 每条都要能验证。"怎么验"一列：
> - **U** 单元测试（Vitest，core 和 react）
> - **E** 端到端测试（Playwright，连本地测试服务，见 `08-test-services.md`）
> - **S** 截图回归
> - **C** 脚本检查（lint、构建、体积）
>
> 测试名称里带编号，`npm run trace` 汇总每个编号对应的测试。
>
> v5 第 9 节第 1–10 条与本文的对应关系见第 10 节。

| 编号 | 标准 | 怎么验 |

| AC-MOD-01 | 两个测试服务的 `$metadata`（XML 和 JSON 各一份，存为仓库里的固定样本）都能解析成模型；同一服务的 XML 和 JSON 得到相同模型（ANN-70） | U |
| AC-MOD-02 | 注解三层合并：服务自带 < 注解文件（多份按顺序）< 覆盖层；同一「目标 + 术语 + 限定符」整条替换（ANN-71、72） | U |
| AC-MOD-03 | 零注解的仿 Northwind 服务推导出列、筛选字段、页头、区块（ANN-60–64），并在 `ui.derived` 里标明 | U |
| AC-MOD-04 | `02-annotation-coverage.md` 里标"一期"的每个术语都有带编号的单元测试，并且通过 | U、C（`npm run trace`） |
| AC-MOD-05 | 模型带 `version` 字段；无效的注解引用不抛异常，写进 `warnings` | U |

## 2. 数据层与查询

| 编号 | 标准 | 怎么验 |
| --- | --- | --- |
| AC-DATA-01 | 查询生成符合 Q-01–Q-10：`$select` 只含所需字段，经导航的文本进 `$expand($select)` | U |
| AC-DATA-02 | 条件模型的语义：同字段包含为或、排除取反后为且，字段之间为且；14 个运算符都覆盖；每种 Edm 类型的字面量格式正确 | U |
| AC-DATA-03 | **服务器接受**：每一类查询（列表首块、续块、排序、各运算符的筛选、搜索、计数、展开、对象读取、子表、值帮助、值帮助搜索）在本地测试服务（`@sap-ux/fe-mockserver-core`）上返回 200，结果与内存数据提供者对同一请求的结果一致 | E |
| AC-DATA-04 | `Edm.Decimal` 和 `Edm.Int64` 全程是字符串：服务端返回字符串，显示时不经过浮点数，例如 `12345678901234567.89` 显示时不丢精度 | U、E |
| AC-DATA-05 | 日期：`Edm.Date` 不做时区换算；`Edm.DateTimeOffset` 按指定时区显示；按日筛选 `DateTimeOffset` 时生成该时区的 `[00:00, 次日 00:00)` | U |
| AC-DATA-06 | 错误：OData 错误格式解析成 `ODataError`，区分页面级和字段级；非 JSON 错误也能显示；查询失败时表格上方显示消息条 | U、E |
| AC-DATA-07 | 能力降级：服务不支持 `$search` 时没有搜索框；不支持 `$count` 时没有条数，并且不发 `$count`；不可筛选的字段不在筛选栏和适配筛选里；不可排序的列不能排序（服务端用 Capabilities 注解声明，E 测试检查**没有发出**会失败的请求） | U、E |
| AC-DATA-08 | 查询形状对照：`query-shapes.md` 第 2 节的每条规则，在采购订单服务的同类操作上有一条端到端测试，记录实际发出的 URL 并断言其形状 | E |

## 3. 列表页

| 编号 | 标准 | 怎么验 |
| --- | --- | --- |
| AC-LR-01 | 打开列表页时，默认变体自动执行，表格有数据，页头折叠；关闭自动执行后再打开：页头展开，表格显示 "To start, set the relevant filters." 或"请先设置筛选条件"；查不到数据时显示对应的无数据文案（LR-13、LR-15、LR-22） | E |
| AC-LR-02 | 手动模式：改了条件后表格出现遮罩，点"执行"后遮罩消失并重新查询；即时模式（配置开关）：改条件后不超过 500ms 就重新查询（LR-07） | E |
| AC-LR-03 | 页头折叠后，标题区显示筛选摘要，文案按 0、1、n 个分别处理，超过 5 个加省略号（LR-03） | U、E |
| AC-LR-04 | 筛选栏：搜索框排第一、不带标签；"执行"在"适配筛选 (n)"前面，都靠右；n 等于有条件的字段数（LR-08） | E |
| AC-LR-05 | 筛选字段支持多值令牌、排除、范围、日期范围、文本包含；固定值字段显示为多选下拉；搜索和筛选同时生效（LR-05、LR-10） | E |
| AC-LR-06 | 值帮助：输入时有联想；对话框能搜索、选择、定义条件（包含和排除）；选中的值以令牌显示为"文本 (代码)"（LR-11） | E |
| AC-LR-07 | 适配筛选：可以添加和移除筛选字段；有条件的字段不能被移除（LR-09） | E |
| AC-LR-08 | 变体（存数据库）：另存为、设为默认、自动执行、改名、删除；变体保存条件、搜索词、筛选字段、列（顺序和显隐）、排序；条件和变体不一致时显示"已修改"；刷新浏览器后默认变体仍然生效，数据来自服务端的 `Variants` 实体集（LR-02） | E |
| AC-LR-09 | 网格表格：服务端排序（点列头）；滚动时按块加载；有 10,000 行的实体能滚到底（LR-30、LR-32） | E |
| AC-LR-10 | 个性化对话框：列的显隐和顺序、排序；确认后表格和查询（`$select`、`$orderby`）同时更新（LR-19） | E |
| AC-LR-11 | 导出：导出的 xlsx 列与界面一致，行与当前筛选和排序一致，有上限（LR-20） | E |
| AC-LR-12 | 行导航：有对象页的行显示导航指示器，点击进入对象页；行上按 Enter 也能进入（LR-24） | E |
| AC-LR-13 | 页头下沿正中有展开 / 折叠和固定按钮；表格向下滚动时页头折叠、滚回顶部时展开；固定后滚动不折叠；折叠会取消固定；点击标题栏空白处切换页头（LR-12、[DP] Snap on Click、Pinning） | E |
| AC-LR-18 | 即时模式是默认：没有"执行"，改条件后立即查询；即时模式下"另存为"没有"自动执行"选项（LR-07、LR-02） | E |
| AC-LR-19 | 键盘：焦点进入页头时页头展开，离开到内容区时折叠（[DP] Keyboard Interaction） | E |
| AC-LR-14 | 初始焦点：页头展开时在"执行"（手动）或第一个筛选字段（即时）；有空必填字段时在它上面；页头折叠时在表格第一行（LR-14） | E |
| AC-LR-15 | 单元格类型：文本排列、金额加币种（按币种的小数位）、数量加单位、日期、状态（语义色加图标）、评分、进度、图片，全部只靠注解配置（LR-31） | E |
| AC-LR-16 | 必填筛选：有空的必填字段时，"执行"不发查询，字段显示错误（LR-06） | E |
| AC-LR-17 | 键盘：在表格里用方向键在单元格之间移动；Tab 能到达筛选栏、表格、工具栏的每个控件（LR-34） | E |

## 4. 对象页

| 编号 | 标准 | 怎么验 |
| --- | --- | --- |
| AC-OP-01 | 页头：标题、副标题、头像（采购订单服务的供应商标志）、页头 Facet（表单、关键值、评分、进度）；Facet 放不下时换行；向下滚动折叠，向上滚动展开，可固定；折叠后头像缩小移到标题左边（OP-01–OP-04） | E |
| AC-OP-02 | 锚点导航：点击滚动到区块；滚动时当前锚点跟着变；有两个以上子区块的锚点带下拉箭头；放不下的锚点收进"⋯"溢出菜单；窄屏时变成下拉框（OP-08） | E |
| AC-OP-03 | 页签导航（采购订单默认）：一次只显示一个区块；每个页签打开前就显示条数；切换页签时页签栏位置不变、不折叠页头；页头已折叠时保持折叠，新页签从页签栏下方开始（OP-09、[OP] Tables） | E |
| AC-OP-10 | 锚点导航：点第一个锚点回到页面顶部，页头展开（规范未写明，按 `11-guideline-gap-report.md` U-2） | E |
| AC-OP-11 | 页头：点击标题栏空白处切换；固定时点"折叠"会取消固定；页头超过视口 60% 时不提供固定；头像点击放大；键盘焦点离开页头时折叠、进入时展开（[DP]、[OP] Image Facet） | E |
| AC-OP-12 | 锚点导航：页面内容比窗口短时，最后一个区块之后留出空白，每个锚点都能把区块滚到锚点栏下方（与 UI5 对象页一致） | E |
| AC-OP-04 | 标题去冗余的 4 种情况都有示例，并按 OP-12 显示 | E |
| AC-OP-05 | 表单：标签在上方，列数随内容区宽度变化：<600 是 1 列，600–1023 是 3 列，1024–1439 是 4 列，≥1440 是 6 列（OP-13） | E |
| AC-OP-06 | "显示更多 / 显示更少"能展开和收起 `PartOfPreview = false` 的内容（OP-11） | E |
| AC-OP-07 | 子表：先显示 10 行，有"更多"按钮，每次再加载 20 行；有搜索框；能排序；子表在区块接近视口时才发请求（OP-14、OP-16） | E |
| AC-OP-08 | 页头消息条和区块消息条的插槽位置符合 OP-17；对象读取失败时显示页面级错误 | E |
| AC-OP-09 | 子对象页：从采购订单的项目子表进入项目对象页；面包屑显示上级标题，点击返回；项目对象页里有定价条件和项目历史两张子表（OP-18、NAV-02、NAV-03） | E |

## 9. 质量门槛

| 编号 | 标准 | 怎么验 |
| --- | --- | --- |
