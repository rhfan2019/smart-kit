# 01 列表页（List Report）规则清单

> 状态：现行 · 2026-11-14。
>
> 出处缩写：
> - **[LR]** SAP Fiori Design Guidelines v1.148《List Report Floorplan》（2026-11-14 用内置浏览器通读）
> - **[REF]** 参考项目 `docs/research.md`、`docs/scope.md`（提炼自 Fiori Elements 的 List Report 页头、内容区、表格类型、表格功能、工具栏、表格行六篇，那六篇标注反映 SAPUI5 1.136）
> - **[APP]** 参考应用 Manage Products（UI5 1.154.0）的观察
>
> 期次：**一期** / **二期** / **不做**。冲突时以 [LR] 为准，在"说明"里写明。规则编号供 `07-acceptance.md` 引用。

## 1. 页面结构

| 编号 | 规则 | 出处 | 期次 |
| --- | --- | --- | --- |
| LR-01 | 页面基于动态页：页头区（标题区 + 可展开 / 折叠的页头内容）和内容区。标题区显示变体管理（或页面标题，必选）、折叠时的筛选摘要、页头工具栏（全局非终结动作，可选）。页头内容放筛选栏（必选）。页头功能按钮：展开 / 折叠（必选）、固定（pin）。内容区：表标题、表工具栏、表格。页脚工具栏只在有消息时显示消息按钮。 | [LR] Components | 一期（页脚消息按钮二期，见 LR-16） |
| LR-02 | 变体管理：整页只用一个变体，保存并恢复筛选、选中的页签、所有表格（列、排序）。可设默认变体，每次打开时选中。可设"选中后自动执行"，只在手动更新模式下提供。不用变体时显示描述当前视图的标题。不推荐表级的布局变体。 | [LR] Variant Management、Table Toolbar、Top Tips | 一期（存数据库，见 `05-data-provider.md`）；表级布局变体：不做 |
| LR-03 | 筛选摘要只在页头折叠时显示："No filters active" / "1 filter active: X" / "n filters active: A, B…"，最多列 5 个，超过时末尾加省略号。 | [LR] Filter Information | 一期 |
| LR-04 | 页头工具栏：放全局非终结动作，例如分享。分享打开动作菜单（发邮件等，存为磁贴依赖 Launchpad）。内容区有自带滚动条的表格（网格表格等）时，显示"显示筛选 / 隐藏筛选"按钮。无权限的动作隐藏；同类动作收进菜单按钮。终结动作不能放在这里。 | [LR] Header Toolbar、Actions §1 | 一期："显示 / 隐藏筛选"，以及插入自定义全局动作的扩展点。分享：二期。存为磁贴：不做 |

## 2. 筛选栏

| 编号 | 规则 | 出处 | 期次 |
| --- | --- | --- | --- |
| LR-05 | 筛选栏可以有搜索框，搜索与筛选条件是"且"的关系。搜索覆盖所有列（不论是否可见）；如果搜索不能作用于多个列，就不提供搜索框。 | [LR] Search | 一期。是否显示搜索框由 `Capabilities.SearchRestrictions/Searchable` 决定，缺省时按服务是否声明支持 `$search` 推导，见 `04-model-spec.md` |
| LR-06 | 筛选作用于内容区的全部表格。建议给必填筛选字段和默认值；页面自动加载时，必填字段必须有默认值。 | [LR] Filters | 一期 |
| LR-07 | 两种更新模式。即时模式（推荐）：条件一变就筛选，搜索框每输入一个字母都触发。手动模式：显示"执行"按钮，点击后才筛选。查询期间所有表格显示忙碌状态。条件与内容不一致时（还没点"执行"），内容区变灰（遮罩）。 | [LR] Filters | 一期。默认手动模式（与 [APP] 和 Fiori Elements 默认一致），可配置为即时模式 |
| LR-08 | 筛选栏布局：搜索框排第一、不带标签；"执行"和"适配筛选 (n)"靠右，"执行"在前。 | [REF] LR-01、[APP] | 一期 |
| LR-09 | 适配筛选：可以把任意可筛选字段加到筛选栏上，也可以移除；有条件的字段不能被隐藏。 | [REF] scope §1 | 一期 |
| LR-10 | 筛选字段控件：按类型提供单值、多值（令牌）、范围、日期范围、文本包含；可以包含，也可以排除。 | [REF] scope §1 | 一期 |
| LR-11 | 值帮助：带 `Common.ValueList` 的字段可以输入联想；也可以打开对话框，在对话框里搜索选择，或定义条件（包含 / 排除）。 | [REF] scope §1、[APP] | 一期 |

## 3. 页头展开与折叠

| 编号 | 规则 | 出处 | 期次 |
| --- | --- | --- | --- |
| LR-12 | 页头内容在向下滚动时折叠、向上滚回时展开（snap on scroll），用户可以固定。**例外**：内容区是网格表格这类自带滚动条的内容时，不提供 snap 和 pin，用户用"显示筛选 / 隐藏筛选"手动展开和折叠。 | [LR] Expand / Collapse；[LR] Components（元素 6a、6b） | 一期。网格表格按例外处理（以 SAP 的说明为准，见 `11-guideline-gap-report.md` C-1）：标题栏用"显示 / 隐藏筛选"，不滚动折叠、不提供固定；点击标题栏空白处也能切换。`SmartListReport` 的 `filterToggle={false}` 改用页头下沿的展开 / 折叠按钮。 |
| LR-13 | 启动时，如果还没有发出查询（表格为空），就展开页头；否则折叠页头。 | [LR] Expand / Collapse | 一期。**与 [REF] LR-06 冲突**：[REF] 写的是"大屏展开、中小屏在自动加载后折叠"，以 [LR] 为准 |
| LR-14 | 初始焦点：页头展开时，落在第一个筛选字段（即时模式）或"执行"按钮（手动模式）；页头里有空的必填字段时，落在第一个空必填字段；页头折叠时，落在表格第一行。 | [LR] Initial Focus | 一期 |
| LR-15 | 尽量不要让页面打开时没有数据：默认变体自动执行。 | [LR] Top Tips | 一期（可通过变体的"自动执行"关掉） |

## 4. 内容区

| 编号 | 规则 | 出处 | 期次 |
| --- | --- | --- | --- |
| LR-16 | 页脚工具栏只在有消息时出现，显示消息按钮，点击打开消息弹窗。 | [LR] Footer Toolbar | 二期（一期只读，消息来源只有查询错误，用消息条显示，见 LR-28） |
| LR-17 | 三种布局。单表：可以切换到图表。多视图：同一数据按状态预筛选；≤3 个视图用分段按钮，>3 个用下拉，放在表标题后面；也可以用纯文字页签，各自带工具栏。多内容：多张不同实体的表，各放一个页签，共用一个筛选栏，页签上显示条数。视图用到的筛选字段不出现在筛选栏。 | [LR] General Layout | 一期：单表。二期：多视图、多内容、图表 |
| LR-18 | 表工具栏：表标题（最好带条数），设置按钮（打开个性化对话框，包括排序、分组、列）。工具栏上不放额外的筛选。另外放所需的动作：依赖选中的动作在没选中或不适用时禁用；不依赖选中的动作（如新建）始终可用；同类动作可以收进菜单按钮。 | [LR] Table Toolbar | 一期：标题和条数、设置、导出，以及插入自定义动作的扩展点（禁用状态按选中行判断）。服务端动作（`UI.DataFieldForAction`）：二期 |
| LR-19 | 个性化对话框：列的显隐和顺序、排序。分组：二期（AG Grid Community 不提供行分组，要另行实现）。 | [LR] Table Toolbar、[REF] LR-09 | 一期：列和排序。二期：分组 |
| LR-20 | 导出：导出当前筛选和排序下的数据为表格文件，列与界面一致，有上限（默认 10,000 行，可配置）。 | [REF] LR-09 | 一期 |
| LR-21 | 复制到剪贴板、显示明细 / 隐藏明细（只有响应式表格有）。 | [REF] LR-09 | 二期 |
| LR-22 | 无数据文案要说明原因：启动后还没筛选时为 "To start, set the relevant filters."；筛选后没有结果时为 "No data found. Try adjusting the filter settings."。 | [LR] Table | 一期（中英文各一套） |
| LR-23 | 吸顶：页签、表工具栏、列头在所有表格类型中都要吸顶。网格表格自带滚动条，这些元素本来就不动。 | [LR] Sticky Behavior | 一期 |
| LR-24 | 行导航：有详情页的行显示导航指示器（右箭头）。列表、树形和响应式表格点击整行导航；网格表格、分析表、树形表点击指示器导航。只对用户有权访问的目标显示指示器。表里只有一个关键标识列。 | [LR] Navigation、Top Tips | 一期（网格表格：点击指示器导航；另外双击行和在行上按 Enter 也会导航，这是键盘可达性的补充） |
| LR-25 | 交叉导航：行里引用其他实体的数据显示为链接，点击打开快速预览（Quick View）。下钻导航：聚合值用链接下钻。 | [LR] Navigation | 二期 |
| LR-26 | 部分处理：批量动作只能处理部分选中项时，先提示"x / y 条无法处理"，说明原因，由用户选择继续还是取消。 | [LR] Partial Processing | 二期 |
| LR-27 | 行内动作：少用；不可用时隐藏，不禁用。 | [LR] Line Item Actions | 二期 |
| LR-28 | 查询失败时，在表格上方显示一条错误消息条（解析 OData 错误格式的 `error.message`），表格保持上一次的数据或空表。 | [REF] LR-22（消息条）、`05-data-provider.md` | 一期 |
| LR-29 | 新建对话框（少于 8 个必填字段时）、工作模式（Worklist / Continuous）、整表编辑、批量编辑。 | [LR] Actions、Working Modes | 二期 |

## 5. 表格

| 编号 | 规则 | 出处 | 期次 |
| --- | --- | --- | --- |
| LR-30 | 表格类型。网格表格：自带滚动条，虚拟化，只用于桌面和平板，冻结列，列宽可拖，列可重排，适合大量数据。响应式表格：所有设备可用，页面整体滚动，滚动续载（"scroll to load" 必须开启），按重要性隐藏列。树形表、分析表：不做。 | [LR] Responsiveness、[REF] LR-19 | 一期：网格表格（列表页）。二期：响应式表格。不做：树形表、分析表。理由见 `adr/002-table-kernel.md` |
| LR-31 | 单元格内容类型来自注解：文本、关键标识（加粗）、金额加币种、数量加单位、日期和时间、状态（语义色加图标）、链接、进度条、评分、图片（头像）。`Common.Text` 按 `UI.TextArrangement` 显示"文本 (代码)"等形式。 | [REF] LR-20 | 一期。微型图表：二期 |
| LR-32 | 点列头排序；服务端排序和分页（网格表格按块加载）。 | [REF] LR-22 | 一期 |
| LR-33 | 选择：多选（复选框）、全选；选中状态用于自定义动作和导出所选行。 | [REF] scope §5 | 一期 |
| LR-34 | 键盘：表格支持网格导航（方向键在单元格之间移动），符合 WAI-ARIA grid 模式。 | v4 第 6.9 节 | 一期 |

## 6. 与服务能力相关

| 编号 | 规则 | 出处 | 期次 |
| --- | --- | --- | --- |
| LR-35 | 能力降级：服务不支持 `$search` 时不显示搜索框；不支持 `$count` 时表标题不显示条数，网格表格改用"有更多就继续加载"；字段不可筛选时不出现在筛选栏和适配筛选里；字段不可排序时，列头不能排序，个性化对话框里也不出现。 | v4 第 6.3 节 | 一期 |

## 7. 一期不做、留在二期的（汇总）

分享菜单、页脚消息按钮、多视图与多内容、图表、复制到剪贴板、响应式表格（含 snap 和 pin、显示明细、手机卡片）、分组、微型图表、快速预览、下钻导航、服务端动作、部分处理、行内动作、新建、编辑、工作模式。
