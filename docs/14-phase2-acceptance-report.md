## 2. 用户截图反馈：列表页页头下沿没有按钮

用户截图里列表页页头展开、表格有数据，页头下沿只有一条空白，没有展开 / 折叠和固定按钮，标题栏右上角是"Hide Filters"。这是 `fd66d40` 之前的版本（`filterToggle` 默认开启）。当前版本在页头下沿正中显示两个按钮，与 SAP 参考应用一致；P2-LRC-06a / 06b 在"页头展开且表格有数据"的状态下断言两个按钮可见、骑在页头下边框上（中心与下边框的距离 ≤ 2px）、水平居中，证据见 [P2-LRC-06a](14-evidence/P2-LRC-06a.png)。

## 4. 偏离规范或规范未写明之处

| 项 | 做法 | 理由 |
| --- | --- | --- |
| 列表页的网格表格用展开 / 折叠和固定按钮、随表格滚动折叠（[LR] 行为一节和 [DP] 特例说不提供） | 保持一期按用户要求的做法；`filterToggle` 可切回"显示 / 隐藏筛选"（P2-LRA-01 有测试） | 用户 2026-11-15 的决定（`11` C-1） |
| 分享菜单只有"发送邮件"和"复制链接" | 不做"存为磁贴"和"SAP Jam" | 依赖 SAP 平台（v5 第 2 节不做；`12` U-3） |
| 图表下钻到同一列表页的表格，而不是"另一个列表页" | 把维度值作为筛选条件、切到表格视图 | 库不知道宿主有哪些页面（`12` U-4） |
| 分组只在响应式表格 | 网格表格没有分组 | AG Grid Community 没有行分组（ADR-002、`12` U-5） |
| Delta 微图表用 `UI.ChartType/Waterfall` 表示 | 本库的约定，写进 ADR-021 和 `02` | UI 词汇表没有 Delta 类型 |
| 多内容时，筛选按属性名作用到各实体集，不适用的条件在页签里列出 | `12` U-6 | 规范只说"同时作用于所有表" |
| 草稿列表的"全部"只列活动实例，草稿用行上的标记表示；"编辑状态"四个选项映射到 `HasDraftEntity` 和 `DraftIsCreatedByMe` | ADR-018、`05` 第 9 节 | 测试服务没有 `SiblingEntity`；Fiori Elements 的"全部"会用自己的草稿替换活动行 |
| 行内新建是"表首的一行输入"，填完后创建 | 不是可编辑的网格行 | AG Grid Community 的固定行编辑代价高；Ctrl+Enter 和位置符合规范 |
| 部分编辑总是对话框 | 不做"字段太多时用子页面" | 示例的页头字段只有 4 个 |
| 应用菜单（Shell bar）由宿主提供 | 库不渲染 | v5 第 2 节不做 Launchpad；P2-OPC-04 检查页面位于宿主顶栏之下 |
| 新建时主键可编辑 | 采购订单号由服务分配，留空即可 | 通用规则：新建时主键和 `Core.Immutable` 属性可编辑 |

## 5. 二期过程中发现并修复的缺陷（不只是样式）

- **测试服务内存泄漏**：长时间运行的端到端测试会让测试服务内存耗尽（4 GB）。用堆采样定位到 `@sap-ux/fe-mockserver-core` 的 `getProperty` 只缓存命中：`$filter` 里的字面量（`'1000'`）在每一行都被当作属性查找一次，每次失败都经过注解转换器的 `resolvePath` 并留下一条消息。前置层改为同时缓存未命中（`apps/mock/server.mjs`），强制 GC 后的堆从每次请求增长约 11 MB 变为稳定在 59 MB。
- 全局动作的溢出宽度按动作组自身的宽度计算，导致所有动作一直在"更多"里；改为按标题行的可用宽度计算。
- 浏览器原生的 `required` 校验拦截了新建表单，本库的校验和消息不出现；表单改为 `noValidate`。
- 多视图把所有视图共有的条件（公司代码 = 1000，必填）也当作视图条件，必填字段从筛选栏消失、查询无法执行；只有在视图之间不同的条件才算视图条件。
- 筛选变化后，网格表格保留了旧查询的选中行，动作按旧行判断可用性；查询变化时清空选择。
- 对象页在渲染期间更新父组件的状态（消息定位回调的注册）；改到 effect 里。
- 页头上微图表按钮的可访问名称与可见数字不一致（axe `label-content-name-mismatch`）；改为用按钮内容命名。
- 校验时页头字段和表单字段重复，同一字段出现两条消息。
- "编辑页头"按钮让没有页头 Facet 的页面也有了页头内容，标题栏变得可交互（违反 [DP] Header Content (1)）。
- 新建模式（直接保存）下没有子区块的区块仍出现在导航栏。
- 窄表（弹性分栏的第一列）工具栏的动作被截断；按表格宽度提前收进"更多"。
- 用户反馈（2026-11-15）：日期范围选不出来。点第一个日期时就写回了"等于该日"，选择器把它当成完整的范围，第二次点击又开始新的范围；字段还显示字面量"ll – ll"（dayjs 的本地化格式需要插件）。现在第一个日期只暂存在组件里，选完第二个才生效（只选一个就关闭时按该日筛选）；格式按语言放进文案表。测试：AC-LR-05（中英文各选一次范围，并检查请求是 `OrderDate ge … and OrderDate le …`）。
- 用户要求按订单类型做多视图（2026-11-15）：在示例的本地注解（覆盖层，`apps/demo/src/annotations.ts`）里加了三个 `UI.SelectionPresentationVariant`（`#TypeNB`、`#TypeFO`、`#TypeUB`），`/po?views=type` 以页签显示、`/po?views=type-switch` 以分段按钮显示，服务端不改。顺带修复：网格表格时页签栏吸顶偏移把页签压到了表工具栏上，页签栏只在响应式表格（页面滚动）时吸顶。测试：P2-LR-02（三个页签的条数之和等于总数、页签栏在工具栏之上、订单类型不在筛选栏）。
- 重跑时发现：页面已向下滚动时，用按钮折叠再展开，页头内容展开在视口之外、立刻又算作"滚走"而折叠。现在展开时同时把页面滚回顶部，与"滚动折叠后展开"的做法一致（[DP] Snap on Click）。测试：P2-DP-04。

- CI 仍未在 GitHub 上运行（按约定没有推送）；Linux 截图基准需要第一次在 CI 上生成。
- 截图基准只覆盖一期的两张页面 × 四个主题；二期的页面用 axe（浅色、深色）和证据截图检查，没有像素级回归。

- 图表只有柱状图和条形图（ADR-021）。
