# ADR-002 表格内核用 AG Grid Community；一期只做网格表格和自动高度两种模式

- **背景**：
  - Fiori 的列表页默认用响应式表格（页面整体滚动、滚动续载、按重要性隐藏列和弹出明细）。
  - 网格表格自带滚动条，适合大量数据。
  - v5 要求长列表虚拟滚动、表格支持键盘网格导航，以及一个万行滚动预算。
- **决定**：
  - AG Grid Community 36.3.0（`ag-grid-community`、`ag-grid-react`），不得引入 Enterprise。
  - 一期 `SmartTable` 提供两种模式：
    - `grid`：列表页使用。自带滚动条，用无限行模型按块从服务端加载，虚拟化。
    - `auto`：对象页子表使用。`domLayout: 'autoHeight'`，没有内部滚动条，用"更多"按钮增长。
  - 响应式表格（含页头 snap 和 pin、弹出明细、手机卡片）放二期。
- **理由**：
  - 一个内核同时覆盖列表和子表，符合"子表就是表格积木加父对象上下文"（v5 第 2 节）。
  - AG Grid 自带虚拟化、列拖动、列宽调整、键盘网格导航和 ARIA grid 角色。
  - 规范 [LR] 明确允许列表页使用网格表格。页头：规范的元素图把展开 / 折叠和固定按钮列为页头功能，行为一节又说网格表格不提供 snap 和 pin、改用"显示 / 隐藏筛选"。按用户要求（2026-11-15）默认用展开 / 折叠和固定按钮，表格向下滚动时页头折叠、滚回顶部时展开；`SmartListReport` 的 `filterToggle` 可切回"显示 / 隐藏筛选"（LR-12）。
- **代价**：
  - 包体积：AG Grid Community 约 300 KB（gzip），作为 peer 依赖，不计入本库的体积预算。
  - 网格表格只适合桌面和平板。
  - 行分组是 Enterprise 功能，所以分组放二期，届时需另行实现。
  - 与 Fiori Elements 默认的响应式表格相比，列表页的页面滚动行为不同，这一点写进验收报告。
- **状态**：采纳。
