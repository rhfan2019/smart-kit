# ADR-020 响应式表格自己实现

- **背景**：[LR] 要求手机上用响应式控件；响应式表格随页面滚动、滚动续载、吸顶、按重要性隐藏列并"显示明细"（pop-in）。AG Grid 的布局模型是自带滚动的网格，不适合随页面滚动和 pop-in。
- **决定**：`SmartTable` 新增 `mode="responsive"`，用语义化的 `<table>` 渲染（`role="grid"` 的键盘导航沿用一期的方向键规则），数据用 `useListQuery` 的增长式分页；列头和表工具栏 `position: sticky`；底部哨兵进入视口时续载。列宽按 `UI.Importance`：容器窄于各级断点时依次隐藏 Low、Medium 列，"显示明细"把隐藏列显示在行下方。分组只在这种表格里提供（`12` U-5）。
- **理由**：页面滚动和 pop-in 用原生表格最简单，体积小；与网格表格共享列模型、选择、动作和导航。
- **代价**：两种表格内核要分别测试；响应式表格不虚拟化（规范要求的是滚动续载，数据量由续载控制）。
- **状态**：采纳。
