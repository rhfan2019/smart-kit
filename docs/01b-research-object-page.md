# 01b 对象页（Object Page）规则清单与导航规则

> 状态：现行 · 2026-11-14。
>
> 出处缩写：
> - **[OP]** SAP Fiori Design Guidelines v1.148《Object Page Floorplan》（2026-11-14 用内置浏览器通读）
> - **[REF]** 参考项目 `docs/research.md` 第 3 节
> - **[LR]** 见 `01-research-list-report.md`
>
> 期次：**一期** / **二期** / **不做**。冲突时以 [OP] 为准。

## 1. 页头

| 编号 | 规则 | 出处 | 期次 |
| --- | --- | --- | --- |
| OP-01 | 动态页头（必选）。组成：面包屑（可选，只显示对象页内的下钻层级）、标题（必选）、标题下方的副标题（可选）、页头内容（可选）、对象标记（可选）、页头工具栏（全局动作，可选）、页头功能按钮（可折叠时必选）。显示模式下页头初始展开。 | [OP] Dynamic Page Header | 一期。对象标记里的草稿图标：二期 |
| OP-02 | 页头随滚动折叠（snap on scroll），可以固定；页头下沿有折叠 / 展开按钮和固定按钮。 | [OP] Header Content、[REF] OP-01 | 一期 |
| OP-03 | 页头内容由 Facet 组成。Facet 从左往右排，宽度适应内容，放不下的换到下一行。 | [OP] Header Content | 一期 |
| OP-04 | Facet 类型：<br>• **表单**：标题可选，不超过 5 对标签和值，值可以是链接。<br>• **纯文本**：默认宽 320px。<br>• **图片**：最多一个，固定在最左边，用头像控件；默认点击放大；页头折叠后缩小并移到标题左边。<br>• **关键值**：标题必选，大号数字或文本；状态文本可以在右边带图标。<br>• **微型图表**：标题、副标题、图表、页脚（写单位）。<br>• **进度**：标题、副标题、进度条、页脚。<br>• **评分**：默认 5 个符号，用半星表示小数。单个评分：标题、副标题、评分。聚合评分：标题、副标题（样本数）、评分、页脚（"x.x out of 5"）。 | [OP] Header Content | 一期：表单、纯文本、图片、关键值、进度、评分。二期：微型图表 |
| OP-05 | 页头工具栏：业务动作用文字按钮；只有通用动作（如分享）用图标；同一个动作不能同时用文字和图标；最重要的放最左边，溢出时从右往左收进菜单。 | [OP] Guidelines · Actions | 一期：插入自定义动作的扩展点，以及溢出规则。编辑、删除、分享和服务端动作：二期 |
| OP-06 | 页头只放关键内容，避免过高。 | [OP] Guidelines | 一期（作为注解的使用建议写进文档） |

## 2. 导航栏

| 编号 | 规则 | 出处 | 期次 |
| --- | --- | --- | --- |
| OP-07 | 两种导航：锚点（默认）和页签。 | [OP] Navigation Bar | 一期 |
| OP-08 | 锚点栏：<br>• 一排锚点链接，在页头下方，始终可见；点击后滚动到对应区块的标题。<br>• 滚动时高亮当前锚点。<br>• 区块有多个子区块时，锚点旁有下拉箭头，打开子区块菜单。<br>• 放不下的锚点收进右侧的溢出菜单（"⋯"），里面分层列出区块和子区块。<br>• 方向键在锚点之间移动。<br>• 小屏幕上，整个锚点栏变成下拉框，显示当前区块。<br>• 标签用标题式大小写。 | [OP] Anchor Bar Navigation | 一期 |
| OP-09 | 页签：一次只显示一个区块，内容区不显示区块标题。页签可以带条数（括号里）。子区块菜单默认开启。小屏幕上用横向滚动，不变成下拉框。 | [OP] Tab Navigation | 一期 |

## 3. 内容区

| 编号 | 规则 | 出处 | 期次 |
| --- | --- | --- | --- |
| OP-10 | 区块只包含子区块，本身不放控件。区块标题显示在导航栏里。 | [OP] Sections | 一期 |
| OP-11 | 子区块：标题（可带条数）、工具栏动作（可选）、内容。"显示更多 / 显示更少"按钮在子区块右下角，用来渐进展示内容。 | [OP] Subsections | 一期（不在预览里的 Facet 由 `UI.PartOfPreview = false` 标记） |
| OP-12 | 标题去冗余（锚点模式）：<br>① 区块只有一个子区块：子区块标题提升为区块标题，没有子区块菜单。<br>② 两个以上子区块：区块标题加各子区块标题，有子区块菜单。<br>③ 第一个子区块只有一张表：隐藏子区块标题，表标题与子区块同名，表标题带条数，表格动作和标题对齐。<br>④ 区块只有一个子区块，且里面只有一张表：表标题就是区块标题，带条数。 | [OP] Content Area Titles | 一期 |
| OP-13 | 表单：<br>• 标签在上方。<br>• 每个表单组占一列，表单标题就是子区块标题，一个子区块只放一个表单。<br>• 列数用 Fiori Elements 的扩展列：S 1 列、M 3 列、L 4 列、XL 6 列。<br>• 没有 `UI.Importance` 时，字段在所有设备上都显示。 | [OP] Forms、Responsiveness | 一期。按 `UI.Importance` 在小屏隐藏字段：二期 |
| OP-14 | 子表的加载方式：<br>• ≤20 行：直接显示。<br>• ≤100 行：用"更多"按钮懒加载，初始显示 10 行（不超过 20）。<br>• 50–200 行：建议改用页签导航。<br>• >200 行：只预览 10–20 行，表下方右对齐放"Show All (x)"链接，跳到单独的页面。<br>建议给子表提供搜索，可行时提供排序和筛选；避免分组。 | [OP] Tables | 一期：直接显示、"更多"懒加载（默认每次 20 行）、搜索、排序。二期："Show All (x)" |
| OP-15 | 网格表格放在区块里时至少 4 行；锚点模式下网格表格不超过 4 张。 | [OP] Tables | 一期（对象页子表用表格积木的"自动高度"模式，不会出现内部滚动条，见 `adr/002-table-kernel.md`） |
| OP-16 | 按区块逐步加载：首屏先显示页头和前面的区块，滚动到附近时才加载下面的区块；加载中显示骨架屏。 | [OP] Loading Behavior | 一期 |
| OP-17 | 消息条：<br>• 与整个对象相关的，放在标题和页头内容之间，页头折叠后仍可见。<br>• 与某个区块相关的，放在区块顶部、区块标题之上。<br>• 每个区域最多一条，不叠放。<br>• 简短状态用对象状态，不和消息条重复。 | [OP] Message Handling | 一期：作为插入扩展点提供（页头消息条位置、区块消息条位置），加上对象读取失败时的页面级错误消息条 |
| OP-18 | 子页面：面包屑显示下钻层级；布局动作区的上一条 / 下一条按钮，用于在同级子对象之间切换。 | [OP] Representation of Child Pages | 一期：面包屑。二期：上一条 / 下一条 |
| OP-19 | 页脚工具栏：只放终结动作（编辑和新建模式下的保存、提交；显示模式下的审批、拒绝）。 | [OP] Footer Toolbar | 二期 |
| OP-20 | 编辑、新建、全局编辑时的临时"页头"区块、部分编辑、子对象的行内新建、草稿（未保存修改的图标和弹窗）、删除确认、编辑模式下的初始焦点、消息弹窗。 | [OP] Behavior and Interaction | 二期（一期只留 `mode` 接缝，见 `05-data-provider.md` 第 6 节） |
| OP-21 | 布局块（占 1 / 2 / 3 列）、动态侧边内容。 | [OP] Blocks、Dynamic Side Content | 二期 |

## 4. 导航规则（列表页 ↔ 对象页 ↔ 子对象页）

| 编号 | 规则 | 期次 |
| --- | --- | --- |
| NAV-01 | 列表行的导航指示器（或双击行、按 Enter）进入该行实体的对象页。导航由使用者注入的 `NavigationAdapter` 完成，库本身不改地址栏。 | 一期 |
| NAV-02 | 对象页子表的行，如果它的实体有子对象页（使用者为该导航声明了目标），就显示导航指示器，点击进入子对象页。 | 一期 |
| NAV-03 | 子对象页的面包屑列出从根对象到当前上级的每一层，文字来自各层实体 `UI.HeaderInfo` 的标题。点击面包屑返回对应层级。 | 一期 |
| NAV-04 | 返回时恢复上一页的状态：<br>• 列表页：筛选条件、搜索词、排序、列设置、滚动位置、选中行。<br>• 对象页：页头折叠和固定状态、当前锚点（滚动位置），以及各子表的排序、搜索词、已加载的行数、选中行。<br>状态存进使用者注入的 `PageStateStore`，键由使用者给的命名空间加页面 id 组成。 | 一期 |
| NAV-05 | 链接直达：对象页和子对象页由一条"实体路径"唯一确定，例如 `PurchaseOrders('4500000001')/_Item(PurchaseOrder='4500000001',PurchaseOrderItem='10')`。适配器负责在实体路径和宿主的 URL 之间互相转换。直接打开链接时，页面只靠实体路径就能读取数据，不依赖列表页先加载。 | 一期 |
| NAV-06 | 库不读写 `window.location`、`window.history`，不监听 `popstate`、`hashchange`。 | 一期 |
| NAV-07 | 弹性分栏布局：列表和对象页并排显示。 | 二期 |
