## 0. 摘要

### 0.1 本次反馈的结论

页签（锚点）点击后页头折叠、导航栏位置上移：在**锚点模式**下这是规范规定的行为，不是缺陷。用户期望的"导航栏固定、只换下面的内容"，在规范里是**页签模式**，本项目已经实现，只是示例默认用锚点模式。

另一个支持改用页签模式的依据：示例订单 4500000001 有 150 个项目。按 [OP] Tables 的表格条数规则，这个条数应该用页签模式。

详见第 1 节。

### 0.2 一期范围内的差异（建议修，8 项）

页头：
- D-1：点击标题栏空白处不能展开或折叠页头；
- D-2：固定状态下点"折叠"，固定没有被取消；
- D-3：页头超过屏幕高度 60% 时仍然提供固定；
- D-4：键盘焦点进出页头时，页头不会自动展开和折叠。

对象页：
- D-5：页签模式下，页签上的条数要等访问过该页签才出现；
- D-6：页头图片不能点击放大；
- D-7：示例订单项目多（150 条），却用了锚点模式。

列表页：
- D-8：筛选栏默认是手动模式，规范推荐即时模式。

### 0.3 规范内部冲突（需要用户决定，1 项）

- C-1：用网格表格的列表页，页头该怎么控制。
  - [LR] 的元素图里有展开 / 折叠和固定按钮（6a、6b）。
  - [LR] 的行为一节和 [DP] 的特例一节都说：这种页面不提供"滚动折叠"和固定；[LR] 要求用"显示 / 隐藏筛选"按钮，[DP] 要求用展开 / 折叠按钮。
  - 上一轮按用户要求加了固定按钮和"随表格滚动折叠"，这两点与 [LR] 的行为一节、[DP] 的特例一节都不符。

### 0.4 规范未写明（需要用户决定，2 项）

- U-1：页签模式下切换页签时，页头应保持当前的折叠状态，还是回到顶部（展开）。
- U-2：锚点模式下点第一个锚点时，是滚回页面顶部（页头展开），还是只滚到区块标题（页头保持折叠）。

## 1. 本次反馈：点击页签后页头折叠、页签位置变化

### 1.1 规范怎么说

| 规范 | 内容（转述） |
| --- | --- |
| [OP] Navigation Bar | 区块有两种组织方式：锚点栏（**默认**）和页签。 |
| [OP] Anchor Bar Navigation | 点锚点，页面**滚动**到对应区块，锚点栏保持可见。 |
| [OP] Anchor Bar Navigation · Behavior and Interaction | 点锚点：把页面滚动到所选区块的标题处。 |
| [OP] Header Content | 页头内容在**向下滚动**或点击折叠按钮时隐藏。 |
| [DP] Snap on Scroll | 向下滚动时页头内容滚走，标题栏切换到折叠状态并固定在顶部。 |
| [DP] Pinning the Header Content | 固定后，滚动页面时页头保持展开。 |
| [OP] Tab Navigation | 页签横排在页头下方、**始终可见**；内容区一次只显示一个区块，不能滚到别的区块。 |
| [OP] Tables（条数与加载方式） | 子表超过 50–100 条、少于 200 条时，用页签导航代替锚点导航。 |
| [OP] Guidelines · Tab Navigation | 对象页复杂时用页签导航。 |

把这几条连起来：

1. 锚点模式下，点锚点就是滚动页面；
2. 滚动页面会让页头按"滚动折叠"规则折叠；
3. 页头折叠后标题栏变矮，锚点栏紧贴在标题栏下面，所以它的纵向位置会上移。规范只要求锚点栏"保持可见"，没有要求位置不变。
4. 只有两种情况页头不会折叠：
   - 固定了页头；
   - 改用页签模式：只换内容，不滚到别的区块。

### 1.2 实测

| 编号 | 操作 | 结果 | 与规范 |
| --- | --- | --- | --- |
| E1 | 锚点模式，打开订单 4500000001 | 导航栏顶边 y=297，页头展开 | 一致 |
| E2 | 锚点模式，点 "Items (150)" | 页面滚到 Items；页头折叠；导航栏上移到 y=174 | 一致（规则 1–3） |
| E3 | 锚点模式，再点 "General Information" | 导航栏 y=173，页头仍折叠 | 规范未写明，见 U-2 |
| E4 | 固定页头后点 "Items (150)" | 页头保持展开，导航栏仍在 y=297 | 一致（[DP] 固定） |
| E6–E7 | 页签模式（`&layout=tabs`）依次点 Items、Notes、General Information | 导航栏始终在 y=297，页头不折叠，只换下面的内容 | 一致（[OP] Tab Navigation），即用户期望的效果 |

用户截图里固定按钮是按下状态，但仍反映页头会折叠。在 E4 的条件下复现不出来。

可能的原因：截图前先点过"折叠"再点"展开"。这时固定按钮仍显示为按下，但页头已经按折叠处理过一次。见 D-2：按规范，点"折叠"应该同时取消固定，界面状态才一致。

### 1.3 建议

- **A（推荐）**：采购订单对象页改为默认用页签模式。
  - 订单 4500000001 有 150 个项目，正好落在 [OP] Tables 建议用页签的区间（50–100 到 200 条）；
  - 效果就是用户期望的"页签固定，只换下面的内容"；
  - 改动：只改示例的配置，`SmartObjectPage` 的 `navigation="tabs"` 已经有了。
- **B**：保留锚点模式，接受"点锚点后页头折叠、导航栏上移"。这是规范的默认行为。
- 无论选 A 还是 B，都修 D-2（点"折叠"取消固定）。

## 5. 差异与冲突的说明

### C-1 网格表格列表页的页头控制（需要用户决定）

- 规范：
  - [LR] 元素图：页头功能 6a 展开 / 折叠（必需）、6b 固定；
  - [LR] Header Toolbar 和 Expand / Collapse Behavior：网格表格时用"显示 / 隐藏筛选"，不提供滚动折叠和固定；
  - [DP] Special Case：页面不能滚动时，用展开 / 折叠按钮，不提供滚动折叠和固定。
- 三处一起读：展开 / 折叠这个能力是必需的；但按钮的形态 [LR] 和 [DP] 说法不同（"显示 / 隐藏筛选"按钮 vs 展开 / 折叠图标按钮）；固定和滚动折叠，两篇都说不提供。
- 现状：上一轮按用户要求，同时有展开 / 折叠、固定和随表格滚动折叠（AC-LR-13）。
- 选项：
  - **C-1a（推荐，同时满足两篇规范的共同部分）**：保留页头下沿的展开 / 折叠按钮（满足 6a 和 [DP]）；去掉固定按钮和随表格滚动折叠（满足 [LR] 的行为一节和 [DP] 特例）。
  - **C-1b**：完全按 [LR] 的行为一节，用"显示 / 隐藏筛选"（即设置 `filterToggle`，代码已有）。
  - **C-1c**：保持现状（用户上一轮的要求），在文档里注明与 [LR] 行为一节、[DP] 特例不符。

### D-1 点标题栏空白处展开 / 折叠

- 规范：[DP] Snap on Click。
- 证据：E10；`DynamicPage.tsx` 的标题区没有点击处理。
- 建议：标题区没有可交互元素的位置可以点击，切换展开 / 折叠；鼠标手形，加悬停效果。

### D-2 点"折叠"时取消固定

- 规范：[DP] Pinning the Header Content。
- 证据：E5；`DynamicPage.tsx` 里 `setPinned` 只在固定按钮上调用。
- 建议：折叠时同时取消固定。

### D-3 页头过高时不提供固定

- 规范：[DP] Pinning the Header Content，页头超过屏幕高度 60% 或在手机上时，不提供固定。
- 证据：代码里没有这个判断。
- 建议：按页头高度和视口高度判断，超过 60% 时隐藏固定按钮并取消固定。

### D-4 键盘焦点驱动展开 / 折叠

- 规范：[DP] Keyboard Interaction。
- 证据：代码里没有焦点事件处理。
- 建议：焦点进入页头内容时展开，离开时折叠（固定时不折叠）。

### D-5 页签模式下条数要访问后才出现

- 规范：[OP] Tab Navigation，页签可带条数。
- 证据：E6，打开页签模式时显示 "Items" 而不是 "Items (150)"；切到该页签后才变成 "Items (150)"。原因：条数来自子表的查询，而页签模式只渲染当前页签，其他页签的子表不会发查询。
- 建议：页签模式下，为每个带表格的页签单独发一次只计数的请求（`$count`，不取行）。不可计数的子表（`CountRestrictions`）不显示条数。

### D-6 页头图片点击放大

- 规范：[OP] Image Facet，默认的点击事件是放大图片。
- 证据：头像不可点击。
- 建议：点击时用对话框显示大图，并提供关闭按钮和键盘关闭。

### D-7 示例订单的导航方式

- 规范：[OP] Tables，子表 50–100 到 200 条时用页签导航；[OP] Guidelines，对象页复杂时用页签导航。
- 证据：示例订单 4500000001 有 150 个项目，但默认用锚点模式。
- 建议：见第 1.3 节方案 A。

### D-8 筛选栏默认模式

- 规范：[LR] Filters，推荐即时模式，手动模式只在有性能问题时用。
- 证据：`SmartListReport` 的 `liveMode` 默认关闭。
- 建议二选一：
  - 改为默认即时，示例保留手动作为演示；
  - 保持默认手动（理由：库不知道服务的性能），在文档里说明。

### U-1、U-2（规范未写明）

- **U-1**：页签模式下，页面向下滚动（页头已折叠）后切换页签，现在会回到顶部并展开页头。
  - 另一种做法：保持折叠，只把新页签的内容滚到导航栏下方。
- **U-2**：锚点模式下页头已折叠时点第一个锚点，现在只滚到区块标题，页头保持折叠（E3）。
  - 另一种做法：滚回顶部，页头随之展开。
- 两者规范都没有规定，需要用户选择。
