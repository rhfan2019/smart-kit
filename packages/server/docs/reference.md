### `parseQueryOptions` — function

Reads the system query options of a query string ("a=1&b=2", without "?"). Decoding follows RFC 3986: "+" is a literal plus (not a space), so that time zone offsets in literals survive. Custom options (no "$") are ignored.

```ts
parseQueryOptions(query: string): QueryOptions
```
