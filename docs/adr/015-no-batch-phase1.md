# ADR-015 一期不用 `$batch`

- **背景**：Fiori Elements 把请求打包在 `$batch` 里。
- **决定**：一期每个查询单独发 GET。
- **理由**：
  - 只读场景下，`$batch` 的主要收益是合并同一时刻的多个请求；一期页面同时发出的请求很少（列表首块，或对象加一两个子表）。
  - 单独的 GET 便于缓存、调试和断言 URL 形状。
  - 测试服务的 `$batch` 不具备事务性（ADR-009）。
- **代价**：对象页同时可见多张子表时，请求数会多一些。二期做编辑时，再评估用 `$batch` 实现变更集。
- **状态**：采纳。
