SAPUI5 alignment, stage 4 (docs/31, D43). **Behaviour changes** to match Fiori elements 1.154 on the list report: inline actions get one column each and are disabled instead of hidden; data point, field group, connected fields and contact columns as FE; the row highlight comes from `UI.LineItem@UI.Criticality` (a property's `UI.Criticality` no longer colours cells); toolbar actions in FE order with action groups, copy, `CreateHidden` / `DeleteHidden` and per-row `Deletable`. Filters use the strictest `FilterExpressionRestrictions` and the FE operators, all FE semantic date operators (relative dates as `ge … and le …`), `UI.HiddenFilter`, `tolower` with `Capabilities.FilterFunctions`; conditions of `UI.Hidden` properties are dropped; value helps with qualifiers, FE descriptions and request shapes. Values: `mailto:` / `tel:` links, `HTML5.LinkTarget`, `Common.ExternalID`, `Common.Masked`, `Common.Timezone`, streams; `$expand` selects the target keys and lists no longer select the ETag property. Views and charts: SelectionPresentationVariant → PresentationVariant → LineItem, chart-only pages, FE chart types, automatic analytical / tree tables, `UI.KPI` tags. `Core.IsURL`, `Common.IsUpperCase` and `PropertyModel.criticality` / `isUrl` / `isUpperCase` are removed (D41). See the migration list in docs/25.
